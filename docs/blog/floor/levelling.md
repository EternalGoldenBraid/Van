# Floor Levelling And XPS Support

**Status (2026-10-25):** Active work package (placeholder).

Some regions of the plywood floor currently yield under weight because they are
not fully supported by the XPS underneath. Ensure even, solid support across
the floor with no give before permanent installation.

## Flow

1. Identify all soft / yielding zones before lifting the plywood subfloor.
2. Check where the XPS boards, floor ribs, closed-cell foam, or battens leave
   hollows or uneven contact.
3. Shim, pack, or re-bed the XPS and support battens so the plywood bears
   evenly without flexing.
4. Refit the plywood subfloor and test under load across all bays.
