# Replacement-Air Inlet (*Korvausilma*)

**Status (2026-10-25):** Active work package (placeholder).

Uses the existing hole in the bottom floor above the rivet-hole area as the
replacement-air (*korvausilma* / *räppänä*) inlet for both the
[wood stove](../wood_stove/index.md) and the
[MaxxFan roof fan](../maxxfan/index.md).

## Flow

1. Measure the existing floor hole and underside clearance while the floor is
   lifted.
2. Protect bare metal edges and weather-seal a through-floor collar/spigot.
3. Fit rodent/insect mesh and a closeable interior vent.

**Note:** Keep the vent open whenever the stove is burning or embers remain, and
do not run the MaxxFan in exhaust mode with a live stove.
