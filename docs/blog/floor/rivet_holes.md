# Floor Rivet-Hole Sealing

**Status (2026-10-25):** Active work package. Full coating notes are in the
{download}`floor-sealing logbook <../../floor_sealing_logbook.md>`.

## Flow

1. Lift the floor to expose the old pop-rivet holes (~5.5–6.0 mm, some enlarged).
2. Brush away loose rust on both faces and hole edges, clean, dry, and apply
   CRC Rust Seal converter (or primer on clean bare steel). Let cure.
3. Clamp each hole (inside to outside):
   `bolt -> washer -> bike-inner-tube rubber seal -> van floor -> rubber seal -> washer -> nut`.
4. Verify leak-tightness before covering the floor.
