# Document heater holes, wiring, fuel, intake, and exhaust

**Work package:** [VAN-6](https://linear.app/brutusvan/issue/VAN-6/document-heater-holes-wiring-fuel-intake-and-exhaust)  
**Status:** Done — heater removal recorded, May–June 2026.

## Removal record

- Removed the existing Planar diesel heater upward through the cargo-floor opening.
- Disconnected the pump connector; tucked and zip-tied wiring near the fuel line, with connectors taped.
- Fuel line was plugged following removal; its final support was still to be addressed.
- Exhaust and combustion-air openings were exposed after removal.
- Undid the muffler mounting screw from the body/frame.
- Recorded the wiring connections and control unit in Linear.

The later **sliding-door step-well relocation** is a separate [diesel heater installation work package](../diesel_heater/index.md).
