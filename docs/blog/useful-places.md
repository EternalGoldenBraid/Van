# Useful Places

A lightweight catalog of useful places for the van, separate from the build's work packages. The interactive map and location cards are phone-friendly. The entries are **candidates**, not verified endorsements.

## Van washes

### TEKAR — Hämeenlinna

- [Operator website](https://www.tekar.fi/) · [Navigation](https://www.google.com/maps/search/?api=1&query=TEKAR%20Terminaalitie%2011%20Hameenlinna)
- Terminaalitie 11, Hämeenlinna. Convenient on Tampere–Helsinki trips.
- Reported entrance clearance **4.5 m**, large-vehicle brush washing and underbody pressure washing.
- **Unconfirmed:** compatibility of roof lights/antenna with brushes; whether a brush-free or roof-skip program is available.

### Autopesu-Center — Konala, Helsinki

- [Operator website](https://autopesucenter.fi/pesupaikat.html) · [Navigation](https://www.google.com/maps/search/?api=1&query=Autopesu-Center%20Konala%20Helsinki)
- Malminkartanonkuja 1–3, Helsinki.
- Dedicated large-vehicle wash.
- **Unconfirmed:** numeric clearance, brush-free options and roof accessory handling.

## Important before visiting

The Transit L3H3's factory height is about 2.8 m; larger 255/70 R16 tires, lights and an antenna change its total height. Entrance clearance alone does **not** guarantee brushes will clear roof equipment. Confirm vehicle acceptance and roof treatment with the operator. Prioritize underbody salt removal in winter.

## Maintaining this catalog

The location data is stored in `_static/useful-places.json`; the mobile-friendly map lives in `_static/useful-places-map.html`. These are static files, with OpenStreetMap tiles and Leaflet running in the browser. No API key, database or personal location collection is needed. Use separate entries for any future categories such as service stations, parking or parts suppliers.

Do not publish home addresses, regular routes or sensitive overnight parking information while this GitHub Pages site is public.
