## Layout impact contract

Each work package should contain a `Layout impact` section with one of: **unknown**, **none**, or **identified**, and a link to the relevant layout section when identified. Layout sections link back to their work packages. Do not infer a spatial constraint solely because a feature is proposed.

## Capture plan

1. Empty the cargo area enough to expose the geometry.
2. Record an overlapping video walkthrough with good lighting and coverage, including floor, ceiling, walls, corners and reference dimensions.
3. Evaluate photogrammetry / Gaussian splatting / NeRF for a spatial reference; accuracy and suitability for measurements must be validated against physical dimensions.
4. Add spatial sections and annotate work-package impacts after capture.
