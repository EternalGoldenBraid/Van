# Workstreams

Brief shared session scratchpads: current discussion, next steps and
purchase gaps. Keep them concise and easy to scan in a text editor.

- Name files `YYYY-MM-DD-HHMM-short-description.md`.
- Use short sections and wrapped lines; no Markdown tables.
- Organize work into numbered sections in priority order. Add `Effort:`
  when the number of people needed is known.
- Use brief `Status:`, `Next:`, `Buy:` and `Resolve:` labels as needed.
  Split actions and purchases into bullets; use checkboxes for tracking.
- Keep references beside the relevant work item.
- Update the session's scratchpad as the discussion develops.
- Include the author agent's session ID and exact resume command near
  the top (Copilot: `copilot --resume=<session-id>`).

Add conventions here as the user gives feedback; keep this README small.
